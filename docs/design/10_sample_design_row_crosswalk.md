# `sample design table` Row-by-Row Crosswalk
This file maps each row in the workbook decision tree to a resolver family, analytic pattern set, playbook, and minimum data domains. It is meant to be used with `08_intent_context_resolver.md` and `09_investigation_playbook_catalog.md`.
## How to use this file
- The **agent** tells the resolver which investigation bucket the question belongs to.
- The **patterns** tell Driver Discovery and Evidence Correlator which tests to run.
- The **playbook** tells the Orchestrator which step sequence to execute.
- The **domains** tell Data Access & Validation what must be available before the run can be considered complete.
